Database-safe Migration + Serialized Search & Replace + Auto Redirect + 404 Recovery in one ultra-fast, native WordPress plugin.

## Features

- **Easy Redirects**: Set up 301, 302, 307, 404 redirects easily.
- **Auto Redirects**: Automatically redirect modified posts and pages.
- **404 Monitoring**: Track and log 404 errors, and map them to new URLs.
- **Groups & Organization**: Organize redirects efficiently.
- **Search & Replace**: Database-safe serialized search and replace tool.
- **Import/Export**: Easy migration of settings and redirects.

## Installation

1. Upload the plugin files to the `/wp-content/plugins/nexura-redirects` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the Settings->Nexura Redirects screen to configure the plugin.
