# Security Policy

## Supported Versions

Currently, the following versions of Nexura Redirects are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover any security related issues, please email the project maintainers privately instead of using the public issue tracker. We take security vulnerabilities very seriously and will work with you to resolve them as quickly as possible.

Please provide a detailed report including steps to reproduce the vulnerability. You can expect an acknowledgment of your report within 48 hours.
