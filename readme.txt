== Description ==

**Nexura Redirects** is the ultimate SEO, 301 redirect, and database migration utility designed specifically for WordPress. Whether you are moving your site to a new domain, changing permalink structures, or fixing broken links, Nexura Redirects provides a complete suite of professional tools to keep your SEO rankings safe.

Managing redirects and fixing 404 errors manually can lead to traffic loss and poor search engine rankings. Nexura Redirects automates this process by offering an advanced **404 Error Monitor**, seamless **301 Redirections**, and a powerful **Search and Replace** engine that safely handles serialized database strings.

Designed for speed and security, it runs entirely on your WordPress dashboard without relying on heavy third-party services.

### 🚀 Key SEO & Migration Features

* **Advanced 301 Redirect Manager:** Easily create, manage, and track 301, 302, 307, and 410 redirects. Keep your link juice and SEO rankings intact.
* **Intelligent 404 Error Monitor:** Automatically track all 404 "Page Not Found" errors on your site. Quickly map these broken links to active pages with one click.
* **Auto-Redirect Generation:** Automatically create a 301 redirect whenever a post, page, or product URL is changed.
* **Serialized Search and Replace:** Safely migrate your database or change domains. Our advanced engine safely replaces strings inside serialized arrays without corrupting your data.
* **Wildcard & Regex Support:** Use powerful regular expressions (Regex) and wildcards to redirect entire directory structures dynamically.
* **Export & Import Tools:** Easily backup your redirect rules or migrate them between different WordPress environments using CSV/JSON.
* **Performance Optimized:** Unlike other redirect plugins, Nexura is highly optimized. It uses native WordPress database caching to ensure zero impact on your page load speed.
* **Stealth Mode / White-label:** Hide the plugin from clients and access it securely through a hidden URL parameter.

### 💡 Why Choose Nexura Redirects?

When migrating a website or restructuring content, broken links are your worst enemy. 
**Nexura Redirects is perfect when you need to:**
* Safely move a WordPress site to a new domain with full HTTPS support.
* Catch broken links generated by old marketing campaigns.

### 🔒 Built With Data Safety in Mind

Our Serialized Search & Replace tool is built to handle the most complex WordPress database structures safely. It recalculates string lengths automatically, ensuring your widgets, themes, and page builders (like Elementor) do not break during domain migrations.

== Installation ==

1. Upload the `nexura-redirects` folder to your `/wp-content/plugins/` directory, or install it directly through **Plugins > Add New > Upload Plugin**.
2. Activate **Nexura Redirects** from the WordPress Plugins screen.
3. Navigate to **Tools > Nexura Redirects** in your admin menu.
4. Start creating 301 redirects or use the Search & Replace tool to update your site's URLs.

== Frequently Asked Questions ==

= Does this plugin slow down my website? =
No. Nexura Redirects is meticulously coded for performance. It uses efficient database queries and WordPress object caching to ensure redirect lookups happen in milliseconds.

= Will the Search and Replace tool break my Elementor pages? =
No! Our advanced Search and Replace engine safely handles PHP serialized data. It recalculates string lengths correctly, which means your Elementor data, theme settings, and complex widgets remain perfectly intact.

= Can I redirect old URLs to external domains? =
Yes. You can set up redirects to point to any internal page on your site, or to an external URL.

= Does it automatically track 404 errors? =
Yes, the 404 Monitor logs every request that results in a "Not Found" error. You can review this log and create redirects directly from the 404 list.

= Can I disable the 404 Monitor to save database space? =
Yes, you can easily toggle the 404 monitor on or off from the plugin's settings panel.

= What happens if I uninstall the plugin? =
Uninstalling the plugin via the WordPress dashboard will safely clean up its custom database tables and options, leaving no orphaned data behind.
